# AI 时代个人五能力模型

一套面向**个人**的规范性能力框架：**元认知、逻辑判断、沟通表达、协作编排、系统治理**。

> 前提：AI 是放大器——它放大你的能力，也放大你的缺失。

模型已公理化（四条公理＋五项能力锁定），并经八条边界的对抗式迭代（建模→反驳→测评→主控裁决）完成收窄与定稿。
