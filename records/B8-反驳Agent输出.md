# B8 反驳 Agent 输出：沟通表达 ↔ 协作编排（对照组）

> 任务：本组为对照组，攻击目标有二——①照常攻击候选条目；②专门构造"轴失效场景"，验证轴是否真的稳定

---

## 攻击 1：C-C3 与 O-C3——同义改写的镜像对

C-C3（接口文档写作）的 observable 是"写出的文档清不清晰"——完全被沟通既有条目覆盖（结构化表达＋澄清歧义＋语义转换）；O-C3（契约管理）的 observable 是"约定有没有、放哪、谁更新"——完全被编排"交接接口"覆盖（B3 落文档后该条目已含防一比特确认的标注要求）。两个候选是同一块地的两张地契。**判决建议：双双删除，零晋升。**

## 攻击 2：构造轴失效场景——两个反例，均未能击破

**反例 a（写得极清晰但没人遵守的约定）**：文档字字无歧义，但根本没接入流程，AI-B 实际没用它。
- 归属：沟通满分，编排失败（接口存在但未接入依赖结构）。**轴给出唯一且正确的双账。✅**

**反例 b（粗糙口头约定但大家遵守）**：没有文档，口头说了句"老规矩"，实际运转良好。
- 归属：沟通弱（内容含糊，靠默契补足），编排成功（接口存在且被遵守）。**轴再次给出正确双账。✅**

两个反例是"轴可分"的正面实证：**沟通侧观察对象是文本质量，编排侧观察对象是流程事实，两者可独立变化**——四象限全部有真实场景填充（清晰＋接入、清晰＋未接入、含糊＋遵守、含糊＋混乱），无任何一象限无法归属。

## 攻击 3：遗漏场景扫描

- 约定需要**双方协商**时（AI-B 的开发者提反要求）——协商动作归关系协作（B6 轴：对象是人的关系），仍不出本模型边界。✅
- 约定内容本身的**正确性**（字段设计合不合理）——归逻辑判断（B5 轴）。✅
- 无遗漏。

## 攻击 4：对照组产出——"轴稳定"的形态特征（反哺其他边界）

本组轴稳定的表现可提炼为三条特征，供 B1–B7 复核自查：
1. **四象限可填充**：两个维度的强弱组合都有真实场景；
2. **观察对象类型不同**：一侧看文本／状态，一侧看结构／机制，不需要内省区分；
3. **单动作可切分**：同框动作（写约定）能按"内容 vs 结构"一刀切开，切口平整（无第三种残渣）。

## 五、200 字概括

C-C3、O-C3 是同一块地的两张地契，双双删除，零晋升。两个构造反例（清晰但没人遵守、含糊但运转良好）均未能击破判别轴——沟通看文本质量、编排看流程事实，四象限全部可填充、可归属。无遗漏场景（协商归关系协作、内容正确性归逻辑，均有主）。对照组提炼"轴稳定"三特征：四象限可填充、观察对象类型不同、单动作切口平整，供其他边界复核自查。
